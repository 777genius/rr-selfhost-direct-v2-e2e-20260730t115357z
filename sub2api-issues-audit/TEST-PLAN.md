# Дополнения к execution matrix (предложения, NOT RUN)

Все проверки ниже требуют настоящий adapter/engine boundary, наблюдаемые upstream effects и bounded duration. Issue — источник сценария, не доказательство текущего отказа. Synthetic tests используют только собственные sentinels; live проверки — normalized operator receipt и test-only identity. Этот audit worker не владеет implementation lane и не запускает чужой harness.
